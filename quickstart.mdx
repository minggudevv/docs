## 1. Backup Server

- Masuk ke **Backups** di Pterodactyl panel.
- Buat backup baru sebelum menghapus file lama.
- Pastikan backup berhasil, supaya bisa di-restore jika terjadi masalah.

---

## 2. Hapus File Lama

- Masuk ke **File Manager** server.
- Pilih semua file/folder lama.
- Klik **Delete** untuk mengosongkan folder server.

---

## 3. Upload PaperMC 1.21.8

1. Download PaperMC 1.21.8 versi stabil dari link:

```
https://fill-data.papermc.io/v1/objects/8de7c52c3b02403503d16fac58003f1efef7dd7a0256786843927fa92ee57f1e/paper-1.21.8-60.jar
```

2. Upload file ke **root folder** server melalui **File Manager** Pterodactyl.
3. Rename file menjadi:

```
server.jar
```

> Pastikan nama sesuai dengan egg default agar server bisa dijalankan.

---

## 4. Jalankan Server

1. Klik **Start** di panel.
2. Saat popup **EULA** muncul, klik **“I Agree”**.
3. Server akan membuat folder `world` dan file konfigurasi otomatis.
4. Start ulang server jika perlu, server siap dimainkan.

---

## 5. Catatan Penting

- Selalu pastikan **backup terbaru** sebelum melakukan update atau upload JAR baru.
- Gunakan **Java 21** sesuai rekomendasi untuk PaperMC 1.21.8.
- Sesuaikan RAM sesuai jumlah pemain dan plugin yang dipakai.
